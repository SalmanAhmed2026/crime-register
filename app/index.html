Crime Register — Android app

The download should start by itself. If it does not, tap the button.

Download CrimeRegister.apk

For Android phones. On an iPhone or a computer, use the web version instead.

Installing
  1. Open the downloaded file (from the notification, or Files → Downloads).
  2. If the phone asks, allow Install unknown apps for Chrome, then tap Install.
  3. Open Crime Register, send your Device id to the Administrator, and wait for approval before signing in.

Updating: install the new file over the old one. Your sign-in and cases stay.
